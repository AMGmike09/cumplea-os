# Blooming Birthday

Página web de cumpleaños interactiva para mujer, estilo botánico y elegante con paleta de colores verde sabia (sage green), verde oliva y acentos crema y dorados. Diseño fresco, sofisticado y emotivo. Incluye menú de navegación flotante, portada con foto principal y texto delicado, widget decorativo de calendario de Octubre con el día 16 destacado con una ilustración de hojas o aro dorado, galería interactiva de fotos en marcos estilo Polaroid con toque natural, sección de carta o dedicatoria larga en una tarjeta tono marfil/crema con bordes botánicos, y contenedor integrado para reproductor de música de Spotify.
